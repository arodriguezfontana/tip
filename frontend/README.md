### ¿Como clonar el repositorio?
```bash
git clone https://github.com/arodriguezfontana/tip
cd tip
```

### Ejecución con Docker Compose
```bash
docker compose up --build
```

### Ejecución Local
```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Estará disponible en http://localhost:5173
